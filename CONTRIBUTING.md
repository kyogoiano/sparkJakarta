# Contributing to Spark Community Fork

Thanks for your interest in contributing!

## Ways to Contribute

- 🐛 Report bugs
- 🔧 Fix bugs
- 📝 Improve documentation
- 👀 Review pull requests
- 💡 Suggest features (backward-compatible only)

## Getting Started

1. Fork this repository
2. Create a feature branch: `git checkout -b fix/issue-123`
3. Make your changes
4. Run tests: `gradle clean test`
5. Commit: `git commit -m "Fix: description"`
6. Push: `git push origin fix/issue-123`
7. Open a Pull Request

## Code Review Process

All PRs require:
- ✅ Passing tests (98%+ like current state is acceptable)
- ✅ Review from 1+ maintainer
- ✅ Backward compatibility preserved

## Becoming a Maintainer

Active contributors can become co-maintainers.
Open a discussion in GitHub Discussions!
